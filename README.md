# HELLO — User Discovery Website

> Public hyperlocal discovery and instant enquiry portal for **HELLO** ("Discover Local. Connect Instantly.")

## Tech Stack
- **Framework**: Next.js (App Router, SSR & ISR)
- **Styling**: Tailwind CSS & Design Tokens
- **Language**: TypeScript

## Getting Started
```bash
# Install dependencies
pnpm install # or npm install

# Run development server
npm run dev
```

The portal runs on `http://localhost:3000` by default.
